Publications

  • ISPASS 2026ORAM Characterization

    Oblivious RAM (ORAM) hides a program's memory access pattern from anyone watching memory traffic, at the cost of significant extra bandwidth and latency. We implemented multiple ORAM algorithms and characterized their performance on large-scale inputs, measuring how each scheme's overheads grow with data size so that the cost of access-pattern privacy can be compared across designs.

  • Under ReviewSENTRY: A Distributed Root of Trust for Chiplets

    A distributed hardware Root of Trust for untrusted third-party chiplets, built on Sequestered Encryption (SE). SENTRY provides SE-protected attestation, runtime monitoring, and control-flow integrity, cutting trusted-silicon area 68× (3.4% to 0.05% per chiplet) at 4.97% performance overhead. I designed a custom RISC-V ISA extension and a multi-chiplet gem5 prototype, synthesized the secure enclave in Ibex RTL (48.6 kGE), and modeled attack success probability as a function of monitoring interval.

  • Under ReviewHashStep: A Low-Trust Architecture for Data and Computation Integrity Enforcement

    A RISC-V ISA extension and small hardware enclave that let clients verify an untrusted cloud server ran the right program on unmodified, encrypted data. Each instruction extends a provenance hash that travels with its result, so the client checks the whole computation with one hash comparison. We proved the security guarantee in Lean, verified the RTL with JasperGold model checking, and measured a 3.4× geomean overhead in gem5.

Research

  • OngoingMicroarchitectural Side-Channel Defense

    Reproduced the Hertzbleed DVFS timing attack to recover SIKE keys on Intel x86, then designed, implemented, and evaluated a set of defenses, including core-interleaved pipelining, randomized P-state control, and malicious-input filtering. We characterize each defense's leakage against the information-theoretic bounds of prior work, along with its performance overhead.

  • OngoingSpecFlow: Formally Verified Secure Microarchitecture

    Co-developing SpecFlow, a Lean 4 DSL with mechanized semantics for proving non-interference in pipelined processors. Built an RV64IM core toward booting Linux and modeled Spectre-v1, PortSmash, and Prime+Probe attacks along with defenses that provably close them.

  • OngoingChiplet Interconnect Modeling

    Contributed to a protocol-aware gem5/SST simulation framework for cache-coherent CHI-C2C traffic over UCIe, modeling granule-based flit packing, class-specific credit flow control, and end-to-end backpressure to expose performance effects missed by constant-latency link models.

    Optimized the placement of header cells on a temperature sensor chip using open-source tools such as OpenFASOC and OpenROAD, with Python and TCL.
